Diagnostic — envoi vers Apps Script

Ce test envoie une inscription factice vers l'endpoint exact utilisé par la page. Regarde la réponse brute :

  • `{"result":"success", ...}` → le script a bien reçu et enregistré → vérifie la bonne spreadsheet/tab.
  • `{"result":"error", "message":"..."}` → le script exécuté a planté : le message dit pourquoi.
  • Redirection vers accounts.google.com / 302 → le web app n'est pas accessible pour toi (access « Moi uniquement » ou URL invalide).
  • Erreur réseau CORS → déploiement incomplet ou jamais redéployé.
